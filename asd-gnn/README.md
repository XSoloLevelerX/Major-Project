# asd-gnn

ASD classification from resting-state fMRI connectivity using graph neural networks
(ABIDE-I, 871-subject CPAC/filt_noglobal cohort).

Two rules override everything else in this repo:

1. **Nothing fits on test data.** Not the scaler, not the tangent-space reference, not
   the feature selector, not ComBat, not the PCA. If a `.fit()` call can see a test
   index, the project is invalid.
2. **Every result is a JSON file on disk.** No numbers live in notebooks or in anyone's
   head. Tables are generated by `scripts/03_aggregate_results.py`.

## Setup

```bash
conda env create -f environment.yml && conda activate asdgnn
pip install -e .
pytest tests/ -q          # must pass before you write anything new
```

Or without conda:

```bash
python -m venv .venv && source .venv/bin/activate
pip install -e ".[torch,dev]"
```

**Pin `torch-geometric` to your torch/CUDA build and record the exact wheel URLs here.**

## Reproduce the results

No download needed — the synthetic cohort exercises the whole pipeline in about a
minute:

```bash
make smoke
```

The real thing:

```bash
make data          # ABIDE-I ROI time series, cc200 (~1-2 GB)
make features      # QC, cache, and the SHARED split file
make leak          # the leakage suite — nothing below is believable until this is green
make sanity        # label shuffle at chance, sex/site control tasks
make baselines     # M8: SVM/ridge/RF under k-fold and LOSO
make graphs        # M10: GCN / GAT / edge-free MLP control
make tables        # every paper table, regenerated from results/runs/*.json
make figures
```

**Reproduce Table 1** (classical baselines, both protocols) from a fresh clone:

```bash
make setup data features baselines tables
# -> results/tables/table_kfold.md and results/tables/table_loso.md
```

`notebooks/results.ipynb` renders the same numbers as a narrative with figures. It reads
`results/runs/*.json` and contains no pipeline logic — that is a hard rule, because
anything living only in a notebook cannot be tested or reproduced.

## Data contracts

The only five shapes that move between modules:

| name | type / shape | notes |
|---|---|---|
| `pheno` | `pd.DataFrame` indexed by `SUB_ID` | `FILE_ID, SITE_ID, y, age, sex, fiq, eye, mean_fd, site_code` |
| `ts_dict` | `dict[int, np.ndarray]` | `SUB_ID -> (T, R)` float32; **T varies across sites** |
| `conn` | `np.ndarray (N, R, R)` | symmetric, diagonal 0 |
| `X` | `np.ndarray (N, R(R-1)/2)` | vectorised **upper** triangle |
| `graphs` | `list[Data]` | one per subject (brain-graph mode) |

`y` is int, `1 = ASD`, `0 = TC`. The conversion happens exactly once, in
`data/phenotype.py`; `DX_GROUP` is never touched again anywhere else.

Time series are ordered to match `pheno.index` everywhere. `stack_aligned()` is the only
sanctioned way to go from the dict to a list.

## Where the results live

Each run writes `results/runs/<run_id>.json` with the resolved config, the git commit,
per-fold metrics **and per-fold predicted probabilities**. The probabilities are what
make DeLong tests possible later; re-running a thousand folds because they were not
saved is a genuinely miserable afternoon.

Splits are generated once by `scripts/01_build_features.py` and cached to
`data/processed/splits.json`. Every model reads the same file — that is what makes
paired statistical comparisons across models valid.

## Debugging, ranked by how much time it will cost you

| symptom | most likely cause |
|---|---|
| accuracy > 85% | tangent / ComBat / feature selection fitted outside the fold |
| accuracy stuck at 53% | graph too dense — print `mean_degree(graphs)` first |
| loss NaN at epoch 1 | zero-variance ROI leaking a NaN correlation, or lr too high |
| train 100% / val 55% | expected at N=871; reduce hidden dim, raise dropout and weight decay |
| results differ across runs | unseeded DataLoader shuffle or non-deterministic PyG scatter |
| LOSO std ±20 points | tiny sites; report per-site n and weight the mean |
| population GNN predicts one class under LOSO | held-out site disconnected because edges require matching site |
| explainability ROIs look random | check the `vec_to_matrix` round-trip, then saliency stability across folds |
| PyG shape errors after collation | custom `Data` attributes must be tensors or scalars, never strings |
